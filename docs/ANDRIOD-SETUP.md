# Android setup guide

## Recommended phone setup

1. Install or update Chrome on Android.
2. Sign in to GitHub in Chrome.
3. Open the repository and create a Codespace.
4. In Codespaces, use the browser-based VS Code interface.
5. Open the integrated terminal from the menu.
6. Keep the Codespaces preview tab available for testing the running application.

## Optional local editor

Acode can be used for quick local edits and viewing files. For work inside a Codespace, the browser editor is the primary editor because it operates directly on the remote workspace filesystem.

Do not download a repository copy and edit it locally if you expect those changes to appear automatically in the Codespace. Local and cloud copies are separate unless you explicitly synchronize them with Git.

## Mobile usability tips

- Use Chrome's desktop-site mode if the editor layout is cramped.
- Use landscape orientation for code editing where practical.
- Connect a Bluetooth keyboard for longer sessions.
- Keep Codespaces stopped when not in use to avoid consuming included compute hours.
- Set forwarded application ports to Private unless public access is intentionally required.
